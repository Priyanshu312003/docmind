# DocMind

A RAG (Retrieval-Augmented Generation) pipeline built from scratch in Python.

Ask questions from your own PDF documents — no LangChain, no shortcuts.

## Stack
- OpenAI (text-embedding-3-small + gpt-4o-mini)
- ChromaDB
- PyMuPDF
- Python
